# Mi App de Vida

Página personal que presenta valores, talentos, pasiones, impacto y propósito mediante la metáfora de una aplicación. Es un proyecto de HTML y CSS; no almacena datos ni tiene un backend.

## Ejecutar

Clona el repositorio y abre `index.html` en tu navegador, o sirve la raíz con `python -m http.server 8000` y visita http://localhost:8000.

## Estructura

- `index.html`: navegación por anclas y contenido semántico.
- `style.css`: diseño de escritorio, adaptación móvil y preferencias de movimiento reducido.

## Comprobar

Recorre los seis enlaces laterales; cada uno debe llevar a su sección. A 375 px de ancho las tarjetas aparecen en una columna y el menú deja de ocupar una barra lateral fija. No requiere paquetes, claves ni base de datos.
